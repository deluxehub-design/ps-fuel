# PS Fuel 3.4.0 inventory items

Use only the file matching your inventory/framework and merge the entries into its item registry.

- `tgiann-inventory.lua` contains TGIANN-style definitions.
- `qbox-items.lua` contains QBox/QBCore-style definitions.

Required 3.4.0 gameplay items:

- `fuel_repair_kit`
- `ps_fuel_card`
- `ps_fuel_loyalty_card`
- `siphon_hose`
- `fuel_can_5l`
- `fuel_can_10l`
- `fuel_can_20l`
- `diesel_can_20l`
- `fuel_filter`
- `fuel_pump`
- `fuel_injectors`
- `fuel_tank`
- `ev_battery_module`
- `charging_port`

Portable containers and fleet cards must support metadata and should be unique/non-stackable.

- `home_charger_kit`
- `business_pump_kit`
