# PS Fuel v3.4.0

Vehicle Energy, Fleet & Station Operations release.

This release keeps the standard 0–100 `GetFuel`/`SetFuel` contract while adding real litres/kWh, fuel quality, vehicle wear, fleet billing, station operations and EV energy systems internally.

Before publishing:

1. Tag the GitHub release `v3.4.0`.
2. Use `PS Fuel v3.4.0 — Vehicle Energy, Fleet & Station Operations` as the release title.
3. Merge the appropriate inventory items from `install/items`.
4. Test the staging checklist in `TESTING.md`.
5. Perform a full FiveM server restart after upgrading.
